# Архитектура ядра NMS Next-Gen (Rust + WASM)

Документ описывает батизовую архитектуру нового приложения NMS, перенесенного на язык **Rust** с поддержкой мозаичной архитектуры **WASM-модулей**.

---

## 🏛️ Компоненты ядра (`nms-core`)

1. **`AppConfig` (`crates/nms-core/src/config.rs`)**:
   - Единая структура настроек подключения, портов, путей к модулям `/modules/` и флагов режимов запуска (`--server` vs GUI).

2. **`EventBus` (`crates/nms-core/src/bus.rs`)**:
   - Вычислительно эффективная шина событий на базе канала `tokio::sync::broadcast`.
   - Обеспечивает Pub/Sub доставку событий между сервисами ядра и изолированными плагинами.

3. **`Axum Web Server` (`crates/nms-core/src/server.rs`)**:
   - HTTP REST API и WebSocket сервер.
   - Базовый эндпоинт состояния: `/api/v1/health`.

4. **`CLI / Server Entrypoint` (`crates/nms-cli/src/main.rs`)**:
   - Точка входа в бинарный файл `nms`.
   - Парсинг флагов `--server`, `--port`, `--host`.

---

## ⚙️ Регламент логирования и комментариев
* **Комментарии в коде**: Пишутся строго на русском языке.
* **Логи трассировки (`tracing`)**: Формируются строго на английском языке.
