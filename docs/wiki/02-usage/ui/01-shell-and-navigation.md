# 🖥️ Оболочка пользовательского интерфейса (Frontend Shell)

## 1. Назначение и концепция

Пользовательский интерфейс платформы представляет собой микрофронтенд-оболочку на **Vue 3 + Vite + Tailwind CSS**, работающую как в браузере (при подключении к Headless серверу), так и внутри нативного WebView (в режиме Tauri Desktop).

Оболочка решает следующие ключевые задачи:
- **Единая аутентификация и сессия**: хранение JWT токена в Pinia Store, автоматическое обновление и валидация прав доступа через RBAC guards.
- **Динамический роутер (Dynamic Route Registration)**: модули регистрируют свои страницы в рантайме на основе секции `routes` в `manifest.yaml`.
- **Реактивная шина данных (WebSocket Client)**: прямое подключение к `/ws/events` для обновления дашбордов и виджетов в реальном времени.
- **Движок мультиязычности (i18n)**: загрузка объединенного словаря ядра и активных плагинов через `/api/v1/system/i18n/{locale}`.

---

## 2. Архитектура навигации и бокового меню (Sidebar)

Боковое меню формируется динамически:
1. Системные разделы ядра (Дашборд, Пользователи, Модули, Аудит, Настройки).
2. Пользовательские разделы плагинов, сгруппированные по полю `menu.group` из манифеста.
3. Фильтрация пунктов меню на основе прав текущего пользователя (`meta.permissions`).

---

## 3. Взаимодействие с бэкендом (Data Flow)

```text
[ Vue Shell Component ]
       │
       ├──► HTTP Request (Axum REST API) ──► /api/v1/modules, /api/v1/users
       │
       ├──► WebSocket Stream (/ws/events) ──► Real-time Telemetry & Alerts
       │
       └──► Dynamic Module Import ──► /modules/{plugin_id}/dist/ui.js
```
