# 🌐 WIT Интерфейс `nms:core/i18n`

## 1. Назначение и роль в ядре

Интерфейс `nms:core/i18n` позволяет гостевому коду плагина выполнять локализацию системных сообщений, названий и шаблонов с интерполяцией параметров через встроенный реестр переводов ядра.

---

## 2. Полный код WIT спецификации

```wit
interface i18n {
    /// Получить локализованную строку с подстановкой параметров
    translate: func(key: string, params: list<tuple<string, string>>) -> string;
}
```

---

## 3. Пример использования на Rust (Гостевой код плагина)

```rust
use crate::bindings::nms::core::i18n;

pub fn format_greeting(user: &str) -> String {
    i18n::translate("my-plugin.greeting", &[("username", user)])
}
```
