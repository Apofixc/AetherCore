# 🌐 WIT Интерфейс `nms:core/i18n` — Интернационализация и Локализация

## 1. Назначение и концепция работы

Интерфейс `nms:core/i18n` предоставляет гостевому WASM-коду доступ к централизованному мультиязычному реестру ядра `I18nRegistry`. Это позволяет динамически подставлять локализованные сообщения на языке текущего пользователя системы без хардкода строк в исходном коде.

### Порядок резолвинга переводов:
1. Плагин поставляет свои локали в ZIP-архиве (`locales/ru.json`, `locales/en.json`).
2. При загрузке ядро регистрирует ключи с неймспейсом `{plugin_id}.{key}`.
3. При вызове `i18n::translate` ядро ищет ключ в словаре запрошенной локали.
4. Если перевод не найден, ядро автоматически выполняет fallback в системную локаль по умолчанию (`ru`), либо возвращает исходный ключ с подставленными параметрами.

## 2. Полный код WIT спецификации (`nms-core.wit`)

```wit
package nms:core@2.0.0;

interface i18n {
    /// Выполнить перевод строки по ключу с подстановкой параметров
    ///
    /// # Параметры:
    /// - `key`: идентификатор ключа (например, "my-plugin.device_status")
    /// - `params`: список пар ключ-значение для интерполяции в шаблон `{param_name}`
    ///
    /// # Возвращаемое значение:
    /// - Итоговая локализованная строка
    translate: func(key: string, params: list<tuple<string, string>>) -> string;
}
```

## 3. Пример JSON словарей локализации плагина

Файл `plugins/my-sensor/locales/ru.json`:
```json
{
  "title": "Сетевой Сканер",
  "status.scanning": "Выполняется сканирование подсети {subnet}...",
  "status.completed": "Сканирование завершено: найдено {count} активных узлов за {duration} сек.",
  "errors.permission_denied": "Недостаточно прав для отправки Raw ICMP пакетов"
}
```

Файл `plugins/my-sensor/locales/en.json`:
```json
{
  "title": "Network Scanner",
  "status.scanning": "Scanning subnet {subnet} in progress...",
  "status.completed": "Scan completed: found {count} active hosts in {duration}s.",
  "errors.permission_denied": "Insufficient permissions to send Raw ICMP packets"
}
```

## 4. Практический пример использования на Rust (WASM Guest)

```rust
// src/lib.rs
#[allow(warnings)]
mod bindings;

use bindings::nms::core::i18n;
use bindings::nms::core::logger::{self, LogLevel};

pub fn notify_scan_finished(subnet: &str, found_count: usize, elapsed_sec: f64) {
    let count_str = found_count.to_string();
    let duration_str = format!("{:.2}", elapsed_sec);

    // Подготовка параметров для интерполяции в шаблон
    let params = [
        ("subnet", subnet),
        ("count", count_str.as_str()),
        ("duration", duration_str.as_str()),
    ];

    // Запрос локализованного сообщения через ядро
    let message = i18n::translate("my-sensor.status.completed", &params);

    logger::log(LogLevel::Info, &message);
}
```
