# 🎨 3 Уровня поставки интерфейса модулей (UI Delivery Levels)

Платформа поддерживает гибкую трехуровневую модель поставки пользовательского интерфейса (Dual-Mode Mainstream):

---

## Уровень 1: Schema-driven UI (Zero-Frontend)
- **Для кого**: простые плагины, микросервисы и драйверы без кастомной фронтенд-логики.
- **Как работает**: разработчик определяет секцию `config_schema` в `manifest.yaml`. Фронтенд-оболочка Vue Shell автоматически генерирует форму настроек с валидацией, переключателями и локализованными подсказками.

---

## Уровень 2: SFC Development Mode (vue3-sfc-loader)
- **Для кого**: быстрая разработка и отладка в режиме `--dev`.
- **Как работает**: модули хранят Single File Components напрямую в `frontend/views/*.vue`. В режиме разработки клиентский браузер компилирует SFC на лету через `vue3-sfc-loader` без необходимости предварительной сборки.

---

## Уровень 3: Предсобранный ESM Bundle (Production Mode)
- **Для кого**: высокопроизводительные модули для продакшена с кастомными дашбордами, графиками и визуализацией.
- **Как работает**:
  - Фронтенд плагина собирается с помощью `vite build --mode module` в единый ESM-бандл `frontend/dist/ui.js`.
  - Модуль упаковывается в архив `.aether-plugin`.
  - Ядро отдает файл через HTTP эндпоинт `/modules/{id}/dist/ui.js` с долгосрочными заголовками кэширования `immutable`.
  - Оболочка Vue Shell подгружает бандл через динамический `import()` и монтирует компоненты в Vue Router и Grid Dashboard.
