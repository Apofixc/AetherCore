# 🛠️ Окружение и стандарты разработки модулей

## 1. Необходимый инструментарий (Toolchain Setup)

Для разработки бэкенд-модулей (WASM) и фронтенд-компонентов требуются:

1. **Rust Toolchain**:
   ```bash
   rustup default stable
   rustup target add wasm32-wasip2
   # Утилита сборки компонентов WebAssembly
   cargo install cargo-component --locked
   ```

2. **Node.js и Yarn/NPM**:
   ```bash
   node -v # v18+ или v20+
   npm install -g vite
   ```

---

## 2. Стандарты оформления кода и архитектурные правила

При разработке модулей платформы действуют следующие обязательные правила:

- **Язык общения и комментариев в коде**: строго **русский язык**.
- **Системные логи ядра**: английский язык (`tracing::info!("Starting plugin...")`).
- **Сквозная локализация строк**: все пользовательские сообщения и названия виджетов обязаны выноситься в `locales/ru.json` и `locales/en.json` с префиксом `{plugin_id}.`.
- **Принцип Lazy Senior Dev Mode**:
  - Никаких избыточных абстракций и тяжелых внешних зависимостей.
  - Повторное использование системных сервисов ядра (`nms:core/*`) вместо повторного изобретения велосипеда.
  - Обязательное покрытие ключевых сценариев unit- и интеграционными тестами в папке `tests/`.
